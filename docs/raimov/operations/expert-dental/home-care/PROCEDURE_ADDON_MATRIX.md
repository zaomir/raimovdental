# Процедура → доп. процедура → продажа

Расширение handoff: к **каждой позиции прайса** — что предложить как следующий клинический шаг и что можно взять в клинике или купить снаружи.

## Легенда колонок

| Колонка | Смысл |
|---|---|
| **Процедура** | Позиция из прайса |
| **Доп. процедура** | Следующий визит / связанная услуга в клинике (запись до ухода) |
| **Продажа** | Материал/средство: `клиника` = витрина/касса; `магазин` = ориентир «можно купить где удобно»; `—` = не предлагать сегодня |

## Правила

- Всё **по показаниям врача**, не автоматом в чек.
- Бренды не канон — только **класс** средства; SKU утверждает клиника.
- «Доп. процедура» — medical recommendation + слот, не «впаривание».
- После удаления в день 0 обычно **нет** retail ухода в лунку; акцент на памятке и контроле.

## Приоритет пилота (не весь прайс сразу)

1. Профгигиена взрослые (все 3 степени)  
2. Кариес / билдап  
3. Эндо 1→2 посещение + коронка  
4. Удаление + план замещения  
5. Брекеты / элайнеры  
6. Коронки / импланты  

Остальные строки матрицы — готовый справочник после medical review.
