# DEC-801 — RAIM SMILE SYSTEM

## Решение

Публичный и стратегический бренд клинической системы переименовывается:

**`Raimov System` → `RAIM SMILE SYSTEM`**

Домен пациентского продукта системы: **`https://raimsmile.com`**.

## Что это меняет

1. Brand lock (`site.ts`, Content Contract, i18n, Stage B, patient-site, doctor/system JSON).
2. Expert Dental Studio публично указывает, что клиника работает по **RAIM SMILE SYSTEM**.
3. Страница Атабека Раимова: он — разработчик системы; секция объясняет пользу для пациента.
4. `raimovdental.com` (Stage B стратегия) вплетает RAIM SMILE SYSTEM в траекторию практики → система → Academy → клиники.
5. Access & Continuity остаётся **прикладным модулем** RAIM SMILE SYSTEM (не отдельным брендом-заменителем).

## Что не меняется

- Master brand клиник / экосистемы: **RAIMOV DENTAL**.
- Academy token: **Raimov Academy** (пока brand token).
- Запрет overclaim: система **формируется**, не «сертифицирована»; без гарантий исхода; факты только из register / clinic OK.
- Deploy только из `zaomir/grainee-v2`.
