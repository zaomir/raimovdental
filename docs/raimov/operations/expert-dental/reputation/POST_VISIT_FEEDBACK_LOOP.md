# Post-Visit Feedback Loop — операционный SOP

Схема сбора отзывов внутри программы мотивации пациентов (Layer A).  
**Не** начисляет баллы и **не** даёт скидку за оценку или публикацию.

## 1. Зачем

| Цель | Как измеряем |
|---|---|
| Больше реальных публичных отзывов на картах | hub → clicks → publish_detected (без гарантии) |
| Покрытие 2–3 площадок одним довольным пациентом | доля циклов с 2+ `platform_clicked` |
| Негатив внутри контура | % 1–3★ с контактом ≤4ч и закрытием ≤48ч |
| Обучение сервиса | еженедельные темы жалоб |

## 2. Роли

| Роль | Делает |
|---|---|
| Администратор | `VISITED`, проверка отправки Hub-ссылки, журнал |
| Управляющий | алерты 1–3★, SLA recovery, ответы на картах, недельный контроль |
| Главный врач / лечащий врач | клинический негатив |
| Маркетинг | Review Hub, UTM/token, сверка публикаций, тексты дожимов |

## 3. Канонический UX (как вы описали)

```text
WhatsApp ──► трекаемая ссылка на Review Hub
                    │
                    ▼
            выбрать 1–5★ на сайте
                    │
         ┌──────────┴──────────┐
         │ любая оценка        │ дополнительно при 1–3
         ▼                     ▼
   три кнопки карт        закрытая форма
   Яндекс · 2ГИС · Google   + opaque-ID алерт
         │
         │ клик (часто уходит и не возвращается)
         ▼
   WhatsApp через 1–2 дня:
   «Спасибо за Google — если удобно, ещё Яндекс/2ГИС»
   + та же ссылка Hub
         │
         ▼
   Hub: Google серая; Яндекс и 2ГИС яркие
         │
         ▼
   повтор до 3 площадок → long-tail → STOP
```

Да: понимание верное. Уточнения ниже — anti-spam и то, что клик ≠ публикация.

## 4. Триггер и тайминг

1. Приём завершён, услуга eligible.
2. Через **60–120 минут** — WhatsApp со ссылкой на Hub:  
   `https://clinic.raimovdental.com/feedback/<token>` (пилот).
3. Вне 09:00–20:00 — на 09:30 следующего дня.
4. Новый CSAT-цикл не чаще 1 / 90 дней на пациента.

Атомарный план внедрения: `IMPLEMENTATION_PLAN_ATOMIC.md`.  
Параллельный агент владеет patient-site (главная, услуги, врачи); этот контур — **только** `/feedback/*`.

## 5. Review Hub — поведение страницы

| Состояние | UI |
|---|---|
| Первый вход | нейтральный CSAT 1–5★ (без «поставьте пять») |
| После любой оценки 1–5★ | одинаковая секция с **тремя** кнопками: Яндекс · 2ГИС · Google |
| После клика площадки | кнопка становится серой / «сделано»; остальные яркие |
| После 1–3★ | дополнительно форма recovery; карты остаются доступны на тех же условиях |
| Opt-out | ссылка «не напоминать об отзывах» → `review_cycle_stopped` |

Трекинг: `hub_opened`, `csat_scored`, `platform_clicked`.  
Факт публикации на карте — отдельное поле `publish_detected` (сверка), не полагаться только на клик.

Хост пилота: **`clinic.raimovdental.com`** (staging, noindex). Cutover path сохранится на `expertdental.kg`.

## 6. Лестница WhatsApp (anti-spam)

| Код | Когда | Текст-смысл |
|---|---|---|
| N0 | +60–120 мин | «Оцените визит» + ссылка Hub |
| N1 | +1–2 дня после 1-го клика | спасибо за площадку A → B/C + Hub |
| N2 | +3–7 дней | оставшаяся площадка + Hub |
| N3 | +7 дней при неполном цикле | одно weekly |
| N4 | +30 дней после N3 | одно monthly |
| STOP | 3 клика / после N4 / opt-out | тишина |

Максимум: **N0 + ≤4 дожима**. Не писать каждую неделю бесконечно.

Если ★ поставлены, но **0 кликов по картам** — один soft nudge через ~2 дня, дальше N3/N4 или STOP.

## 7. Скрипты (черновик → clinic approval)

### 7.1. N0 — ссылка на Hub

> Здравствуйте, [имя]! Спасибо, что были сегодня в Expert Dental.  
> Оцените, пожалуйста, визит — это займёт полминуты:  
> [https://…/feedback/TOKEN]  
> Честная оценка помогает нам становиться лучше.

### 7.2. N1 / N2 — дожим следующей карты

> [имя], спасибо, что отметили нас на [Google Maps]!  
> Если будет удобно — ещё коротко на [Яндекс] или [2ГИС].  
> Уже отмеченные площадки на странице серые, остались яркие:  
> [та же ссылка Hub]  
> Если не хотите напоминаний — ответьте «стоп».

Не писать: «поставьте 5», «за отзыв скидка», «нам нужны только хорошие».

### 7.3. Ветка 1–3 (если написали в чат вместо формы)

> Спасибо за честность — нам важно это исправить.  
> Коротко опишите, что пошло не так, или заполните форму на странице: [Hub#recovery].  
> Управляющий свяжется в ближайшие часы.

### 7.4. N3 / N4 — long-tail

> Здравствуйте, [имя]. Если ещё не успели — на странице остались площадки без отзыва: [Hub].  
> Если уже всё сделали или не хотите напоминаний — просто проигнорируйте или ответьте «стоп».

## 8. Закрытая форма — поля

- `patient_token`, `visit_id`, дата/время;
- врач (код), категория услуги;
- CSAT 1–3;
- только структурированные темы: сервис / ожидание / коммуникация / чистота /
  «результат этапа» / другое — свободный текст не собирается, чтобы не хранить лишний PHI;
- отдельные непредвыбранные согласия на обработку и контакт в WhatsApp;
- recovery: NEW → CONTACTED → IN_PROGRESS → CLOSED / ESCALATED.

Срок хранения recovery-данных — 60 дней. В Telegram/чат уходит только короткий номер
обращения и ссылка на защищённый журнал: оценка, врач, услуга и темы не передаются.

## 9. SLA recovery

| Событие | Срок |
|---|---|
| Алерт после 1–3 | ≤ 15 мин в рабочие часы |
| Первый контакт | ≤ 4 ч рабочих |
| План разбора | ≤ 24 ч |
| Закрытие / эскалация | ≤ 48 ч (сложный клиника — IN_PROGRESS) |

## 10. Журнал

`token | visit_id | doctor_code | service_category | hub_sent_at | hub_opened | score | branch | yandex_click | 2gis_click | google_click | nudges | publish_detected | recovery_status | stopped_reason`

Без диагнозов и лишнего PHI.

## 11. Связь с другими контурами

| Контур | Правило |
|---|---|
| Points / Care | не упоминать на Hub и в дожимах |
| Referral | другое касание |
| QR на стойке | может вести на Hub с `source=desk` |
| Ответы на картах | белая система; негатив сначала внутрь |

## 12. Еженедельный контроль (30 мин)

1. Sent → opened → scored → clicks (1/2/3 площадки).
2. Conversion N0→click1→click2→click3.
3. Recovery open / SLA breach.
4. Publish_detected vs clicks (разрыв ожидаем).
5. Compliance: нет reward, нет pre-filter, нет бесконечного спама.

## 13. Пилот — критерии старта

- [ ] Review Hub страница (CSAT + 3 кнопки + state серых)
- [ ] Token-ссылки и события в журнале/CRM
- [ ] URL Яндекс / 2ГИС / Google (Google — закрыть P0)
- [ ] Авто или полуавто лестница N0–N4
- [ ] Канал алертов 1–3★
- [ ] Тексты утверждены; админы прошли инструктаж

Статус до галочек: **strategy only, not live**.

## 14. Ограничения

Клик по кнопке ≠ опубликованный отзыв.  
Публикация, рейтинг и позиции зависят от пациентов и модерации площадок и **не гарантируются**.
