# DEC-786 — Patient Motivation System

Принята единая трёхслойная система мотивации пациентов Expert Dental:

1. **Layer A Continuity** (DEC-774) — фундамент: триаж, Паспорт, сертификат, pre-book, warm handoff, Reputation / Feedback Loop.
2. **Layer B Expert Care 12** — профилактический абонемент после unit-economics gates.
3. **Layer C Expert Points** — ledger за оплаченное поведение; redeem в гигиену/сервис.

Отзывы **вне** earn/redeem. Reward-for-review запрещён.
