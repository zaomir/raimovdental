# Памятка: Лечение каналов постоянных зубов — первое посещение

**Expert Dental Studio** · Бишкек

Каналы обработаны на первом этапе. **Обязателен второй визит** для завершения.

## Сегодня–завтра
1. Не жевать на этой стороне, пока есть анестезия / сильная чувствительность.
2. Лёгкая ноющая боль 1–3 дня бывает часто.
3. Обезболивающее — только как сказал врач.

## Домашний уход
1. Чистите зубы **мягкой** щёткой 2 раза в день.
2. Межзубные промежутки — нить / ёршики / ирригатор, если рекомендовал врач.
3. Средства можно взять на ресепшене или купить в магазине — важен класс ухода, не бренд.

## Дальше
Запись на **второе посещение (обтурация)** до ухода с ресепшена. После завершения обычно нужна коронка.

## Когда связаться
Боль усиливается день ото дня, отёк, температура, выпала временная пломба.
