# Памятка: Имплантация Straumann

**Expert Dental Studio** · Бишкек

Установлен имплантат. Период приживления критичен.

## Сегодня–несколько дней
1. Холод снаружи — если рекомендовал врач; мягкая пища.
2. Не трогать зону языком; не курить.
3. Лекарства и полоскания — только по схеме врача.

## Уход
- Мягкая щётка рядом с зоной; ирригатор — когда разрешит врач (часто не в первые дни).
- Не жевать на стороне операции до разрешения.

## Дальше
Контроль остеоинтеграции → **формирователь десны (ФДМ)** → слепки → коронка. Запись следующего этапа до ухода.

## Когда связаться
Сильное кровотечение, нарастающий отёк, температура, расхождение швов.
