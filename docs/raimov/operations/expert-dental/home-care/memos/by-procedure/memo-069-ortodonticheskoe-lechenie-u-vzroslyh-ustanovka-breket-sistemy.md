# Памятка: Ортодонтическое лечение у взрослых — установка брекет-системы

**Expert Dental Studio** · Бишкек

Установлена брекет-система. Гигиена теперь ежедневная «мини-процедура».

## Первые дни
1. Возможны натирания — ортодонтический воск на ресепшене/дома.
2. Мягкая пища; нарезать еду мелко.

## Каждый день
1. V-щётка / орто-ёршики / монопучковая — после еды по возможности.
2. Ирригатор сильно помогает вокруг замков.
3. Профгигиена в клинике обычно каждые **1–3 месяца**.

## Дальше
Активации по графику; в конце — ретейнеры. Не пропускайте визиты.
