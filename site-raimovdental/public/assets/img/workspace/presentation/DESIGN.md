# Expert Dental · Presentation for Atabek — visual canon

**Surface:** private noindex HTML deck  
**URL:** `https://raimovdental.com/assets/img/workspace/presentation/`  
**Audience:** Атабек Раимов (владелец Expert Dental Studio)  
**Mode:** persuade + read · meeting / laptop

## Design thesis

Clinic-operational confidence: one calm teal system that shows ownership of daily work — not a marketing splash, not a SaaS dashboard collage.

## Attributes

1. Role clarity (four levels, one logic)
2. Next-action dominance
3. Honest MVP boundaries
4. Evidence via real screenshots
5. Calm clinical authority

## Anti-attributes

- Purple/indigo startup gradients
- Cream + terracotta “AI luxury” look
- Broadsheet / newspaper density
- Fake metrics, invented ROI, stock handshakes
- Card soup, pill clusters, emoji decoration

## Signature idea

**«Одно следующее действие»** — every role screen leads with a single mandatory next step; screenshots prove the chain updates → test → shift → work → handoff → owner control.
