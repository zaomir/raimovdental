# Матрица handoff

Источник названий процедур: `pricing/PRICE_CATALOG.json` (группы). SKU в корзине — **классы**, конкретные бренды утверждает клиника в отдельном approved list (не в Git как «канон бренда»).

## Поля интерфейса администратора

При выборе `procedure_group` или конкретной услуги показать:

| Поле | Тип | Обязательность |
|---|---|---|
| `admin_script` | текст | показать всегда |
| `care_basket[]` | SKU-класс + default_checked | всегда; галочки снимаемы |
| `memo_id` | ссылка на шаблон | всегда |
| `memo_print` | действие | обязательно до закрытия визита |
| `doctor_home_care` | enum от врача | если передано — приоритет над default_checked |

## Приоритет памятки (если несколько процедур за визит)

Чем выше число — тем важнее выдать эту памятку в первую очередь:

| Приоритет | memo_id |
|---:|---|
| 100 | `memo-extraction` |
| 90 | `memo-endo` |
| 80 | `memo-surgery-implant` |
| 70 | `memo-veneers-ortho` |
| 60 | `memo-therapy` |
| 50 | `memo-hygiene` |
| 40 | `memo-pediatric` |
| 30 | `memo-diagnostics` |

## Матрица по группам прайса

### diagnostics — Диагностика / консультация

| | |
|---|---|
| **memo_id** | `memo-diagnostics` |
| **Скрипт админа** | «После консультации — короткая памятка: что будет на следующем шаге и как подготовиться. Средства ухода сегодня обычно не нужны, если доктор отдельно не сказал.» |
| **Корзина (default)** | — (пусто). Если врач отметил класс ухода — показать только его. |
| **default_checked** | нет |

### hygiene — Профессиональная гигиена (взрослые)

| | |
|---|---|
| **memo_id** | `memo-hygiene` |
| **Скрипт админа** | «После чистки важно начать уход уже сегодня вечером новой мягкой щёткой — иначе эффект чистки быстрее сходит. Вот памятка. Могу добавить мягкую щётку к оплате, если удобно; если нет — ориентиры в памятке.» |
| **Корзина** | `soft_brush` (да), `low_abrasive_paste` (нет, если врач не отметил чувствительность/эмаль), `irrigator` (нет) |
| **Если врач: low_abrasive_paste** | добавить пасту, checked=да |
| **Если врач: irrigator** | добавить ирригатор, checked=нет (предложить показать) |

### pediatric — Детский приём (гигиена / кариес / удаление молочного)

| | |
|---|---|
| **memo_id** | `memo-pediatric` |
| **Скрипт админа** | «Для родителей — короткая памятка после детского приёма: что можно есть, как чистить и когда связаться с нами. Если доктор рекомендовал щётку/пасту по возрасту — покажу.» |
| **Корзина** | `kids_brush` (нет), `kids_paste` (нет) — только если врач отметил |
| **Особо** | при удалении молочного зуба приоритет текста про кровотечение/еду — в памятке |

### therapy — Терапия (пломба / билдап / реставрация)

| | |
|---|---|
| **memo_id** | `memo-therapy` |
| **Скрипт админа** | «После пломбы/реставрации — памятка на сегодня и завтра. Обычно рекомендуют мягкую щётку и аккуратную чистку в зоне работы. Добавить щётку к чеку?» |
| **Корзина** | `soft_brush` (да), `low_abrasive_paste` (нет) |

### endodontics — Лечение каналов

| | |
|---|---|
| **memo_id** | `memo-endo` |
| **Скрипт админа** | «После лечения каналов важно знать, что нормально, а когда звонить. Вот памятка. Средства ухода — только если доктор отдельно рекомендовал.» |
| **Корзина** | по отметке врача; иначе пусто |

### surgery — Удаление / хирургия (без импланта)

| | |
|---|---|
| **memo_id** | `memo-extraction` |
| **Скрипт админа** | «После удаления — памятка обязательна: что нельзя делать сегодня и когда бить тревогу. Полоскания и пасты — строго по памятке, не по совету из интернета.» |
| **Корзина** | обычно пусто в день удаления; `soft_brush` только со 2-го дня по тексту памятки / указанию врача |

### implantology / orthopedics — Имплантация / коронки / виниры (ортопедия)

| | |
|---|---|
| **memo_id** | `memo-veneers-ortho` *(или отдельный memo-implant после clinical split)* |
| **Скрипт админа** | «Чтобы сохранить результат, домашний уход важнее рекламы. Доктор обычно рекомендует бережный межзубной уход. Вот памятка — могу показать ирригатор/ёршики, если удобно взять здесь.» |
| **Корзина** | `irrigator` (нет), `interdental_brushes` (нет), `soft_brush` (да) |

> Пока один шаблон `memo-veneers-ortho` покрывает виниры и орто; при клиническом review можно разделить на `memo-veneers`, `memo-implant`, `memo-ortho`.

### orthodontics — Ортодонтия (брекеты / элайнеры / фиксация)

| | |
|---|---|
| **memo_id** | `memo-veneers-ortho` |
| **Скрипт админа** | «После ортодонтического визита — памятка по чистке замков/кап. Без межзубного ухода налёт остаётся. Могу показать ёршики или ирригатор.» |
| **Корзина** | `ortho_brushes` (да), `irrigator` (нет), `soft_brush` (да) |

## Классы SKU (approved list — заполняет клиника)

| Код | Класс | Пример полки (не бренд-канон) |
|---|---|---|
| `soft_brush` | Мягкая зубная щётка | утверждает клиника |
| `low_abrasive_paste` | Низкоабразивная паста | утверждает клиника |
| `irrigator` | Ирригатор | утверждает клиника |
| `interdental_brushes` | Ёршики / межзубные | утверждает клиника |
| `ortho_brushes` | Ортодонтические ёршики / V-щётка | утверждает клиника |
| `kids_brush` / `kids_paste` | Детские по возрасту | утверждает клиника |

Файл с конкретными артикулами и ценами — только у клиники (касса / склад), не в patient-facing Git без прав.

## Контракт UI (для CRM / демо-админа)

```text
onProcedureSelected(procedure) {
  block = MATRIX[procedure.group]
  show(block.admin_script)
  basket = merge(block.care_basket, doctor_home_care)
  require(printMemo(block.memo_id)) before checkoutClose
  record(memo_printed, care_offered, care_taken|declined|external)
}
```
