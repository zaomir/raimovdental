## Колонки (обязательно)

1. Направление лечения
2. Наименование услуги (+ коротко «что входит», если есть в прайсе)

Подписи категорий врачей (можно переименовать, смысл сохранить):

## Как заполнять цены врачей

- Если в прайсе указан диапазон «A – B сом» → A = Врач клиники, B = Главный врач.
- Если указана одна сумма → поставь её в обе колонки и пометь мелким текстом: «уточняется у администратора при записи к конкретному врачу».
- Цены с единицей («/ 1 канал», «/ 1 челюсть», «/ область 1 зуба») сохраняй как есть у обеих категорий.
- Позиции в USD (элайнеры) не переводи в сомы; для подписки по USD примени ту же логику порога, но порог 2000 относится только к суммам в сомах. Для USD: скидка 20% по подписке, без «0 сом».

## Правила подписки Expert Care (жёстко)

Для каждой цены врача отдельно:

1. Если цена ≤ 2000 сом → по подписке = 0 сом.
2. Если цена > 2000 сом → по подписке = цена × 0,8 (скидка 20%), округли до целых сомов.
3. Для диапазонов считай подписку отдельно для «Врач клиники» и для «Главный врач».
4. Рядом с подписочной ценой показывай зачёркнутую обычную цену, если подписка не 0.

Примеры:
- 1 650 сом → по подписке 0 сом
- 2 200 сом → по подписке 1 760 сом
- 550 – 2 000 сом → врач 550 → 0 сом; главный врач 2 000 → 0 сом
- 4 400 сом → по подписке 3 520 сом
