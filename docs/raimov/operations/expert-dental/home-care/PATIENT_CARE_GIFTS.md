# Полезные подарки пациенту (care gifts)

## Зачем

Практика клиник: **полезный** предмет домашнего ухода работает лучше сувенира и лучше флаера.

| Эффект | Почему |
|---|---|
| Клинический | Пациент реально начинает уход «сегодня вечером» (особенно после гигиены) |
| Напоминание о клинике | Щётка / нить / воск — **2 раза в день** в руках; бренд без рекламного давления |
| Доверие | «О нас заботятся после кресла», а не «нас допродали» |
| Handoff | Подарок открывает мягкий разговор о витрине (ирригатор, ёршики) **без обязательной покупки** |

Согласовано с позицией Атабека: врач не продаёт бренды; админ не давит; витрина тихая.  
**Подарок = забота и compliance. Розница на витрине = отдельный выбор пациента.**

---

## Правило «gift ≠ sale»

| | Подарок (gift) | Продажа (retail / витрина) |
|---|---|---|
| Кто | Клиника / админ выдаёт | Пациент берёт по желанию |
| Цена в чеке | **0** (или «включено в визит» — без отдельной строки давления) | По прайсу ухода |
| Брендинг | Сдержанный логотип клиники + телефон / WhatsApp | Можно бренд производителя |
| Объём | Малый, 1–3 позиции | Полная корзина матрицы |
| Скрипт | «Это вам для дома — начать уход сегодня» | «Если удобно взять здесь — покажу» |

Запрещено:

- называть подарок «акцией» или «если купите X»;  
- выдавать дешёвую щётку, которая ломается за неделю (сигнал низкого стандарта клиники);  
- дарить лекарства / «таблетки от боли» без назначения врача;  
- громкий мерч (кружки, ручки, футболки) как основной gift — слабый clinical signal.

---

## Что работает лучше всего (по практикам)

Отраслевой консенсус welcome / recall kits (Tess, Myron, SmileCase и др.):

1. **Мягкая зубная щётка** — №1: польза + 2×/день бренд.  
2. **Нить / флоссеры / ёршики** (мини-набор) — compliance межзубного ухода.  
3. **Орто-воск** — сразу полезен после установки брекетов.  
4. **Мини-паста** (низкоабразивная / sensitive) — только travel-size, не полная туба в gift (туба — retail).  
5. **Лёгкий comfort** после длинного приёма: гигиеничный бальзам для губ (опция; не обязательно в пилоте Бишкек).  
6. **Карманная карточка / QR** с телефоном и «когда звонить» — внутри набора или на ручке щётки.  
7. **Небольшой zip-мешочек** — чтобы набор не выкинули в машине; дороже, но выглядит «как клиника», не «как акция».

Ориентир себестоимости пилота (классы, не прайс закупки; клиника утверждает):

| Уровень | Состав | Ориентир себестоимости* |
|---|---|---|
| **G0 · Solo brush** | 1 мягкая щётка + стикер/карточка | низкий |
| **G1 · Hygiene starter** | щётка + нить/флоссеры + карточка | низкий–средний |
| **G2 · Procedure kit** | G1 + 1 предмет по процедуре (воск / ёршик / детская щётка) | средний |
| **G3 · Welcome pouch** | G1 в zip-мешочке + карточка записи | средний (для новых / VIP / завершение плана) |

\*Точные сом — после прайса поставщика; международный wholesale kit часто ~$1–3/шт без логистики.

## Когда дарить (триггеры)

Привязка к матрице ухода / Continuity — не «всем подряд каждый визит» (иначе обесценится и съест маржу).

| Триггер | Gift | Зачем |
|---|---|---|
| **Профгигиена** (лёгкая / средняя / тяжёлая) | G0 или G1 | «Начать сегодня вечером» — клиника уже рекомендует новую мягкую щётку |
| **Новый пациент / первая консультация** | G1 или G3 | Welcome; телефон на щётке |
| **Пломба / билдап / коронка** | G0 | Бережный уход у края; напоминание о контроле |
| **Установка брекетов** | G2: орто-щётка/ёршики + воск | Сразу снимает боль/натирание; daily brand |
| **Элайнеры** | G0 + мини-щётка для капп **или** retail offer | Каппы дома каждый день |
| **Детский приём (гигиена / пломба)** | Детская щётка G0 | Родители видят бренд у раковины |
| **Удаление / имплант (день 0)** | **Не** retail в лунку; опция: карточка «когда звонить» + мягкая щётка **«со 2–3 дня»** в пакете с памяткой | Compliance без вреда лунке |
| **Запись следующего визита до ухода** | Усиление: G1 «за то, что записались» *только если* клиника хочет soft incentive | Не путать с «скидкой за отзыв» (запрещено DEC-786) |
| **Завершение большого плана** (виниры / имплант-коронка) | G3 | Дорогой touchpoint; открывает soft talk про ирригатор на витрине |

## Брендинг (тихо)

На щётке / карточке / мешочке:

- `Expert Dental` (или утверждённое short name);  
- телефон / WhatsApp из прайса;  
- опционально QR на страницу записи / Instagram (без «акции»).

Не печатать:

- цены, «−20%», названия чужих аптек;  
- медицинские обещания результата;  
- крупный логотип на полручки дешёвой щётки (выглядит как сувенирка).

Качество щётки важнее площади логотипа: мягкая щетина, нормальная ручка, индивидуальная упаковка.

## Как встроить в handoff (без давления)

Скрипт админа после выдачи памятки:

> «В памятке — что делать дома. Вот мягкая щётка от клиники — чтобы начать уход уже сегодня вечером. Если понадобится паста / ёршики / ирригатор — на витрине есть варианты; брать не обязательно.»

Связка с «Рецептом для памяти»:

- ☑ в памятке = «обычно нужно»;  
- gift закрывает **минимум** (часто `soft_brush`);  
- остальные позиции — retail или магазин.

Учёт (пилот):

`gift_sku` · `gift_tier` (G0–G3) · `memo_printed` · опционально `next_visit_booked`.

Подарок **не** даёт % админу (иначе стимул «раздавать всем»). % только с **оплаченной** розницы ухода — по SOP, после пилота.

## Запас отдельно от витрины

| Зона | Назначение |
|---|---|
| **Gift stock** | Запечатанные gift-щётки / мини-наборы; не смешивать с витринными «на продажу» |
| **Витрина (ED-MAT-060)** | Показ и продажа; 1–2 demo; цены тихо |

Пилотный ориентир gift stock (классы):

| Класс | Пилот, шт (2–4 нед.) | Комментарий |
|---|---:|---|
| `gift_soft_brush` | 80–120 | Основной поток гигиены + терапия |
| `gift_floss_mini` | 40–60 | Для G1 |
| `gift_ortho_wax` | 20–30 | Только bonding / активации |
| `gift_kids_brush` | 20–30 | Детский поток |
| `gift_card_qr` | = числу наборов | Печать локально |
| `gift_pouch` (опция) | 15–25 | Welcome / завершение плана |

Пересчёт после 2 недель: gift / визит гигиены; доля `care_taken` после gift (не цель «продать», а сигнал, что gift не блокирует retail).

## Что **не** дарить (или только по исключению)

| Предмет | Почему плохо как gift |
|---|---|
| Полноразмерный ирригатор | Дорого; лучше soft offer с витрины |
| Полная туба пасты премиум | Ломает маржу retail; travel-size ок |
| Лекарства / антисептики | Только по схеме врача, не «подарок с ресепшена» |
| Ручки, брелоки, календари | Слабый clinical signal; не daily oral care |
| Отбеливающие полоски «просто так» | Медицинский / legal риск без показаний |
| «Подарок за отзыв / сторис» | Запрет DEC-774 / DEC-786 |

## Пилот (2 недели)

1. Утвердить **1** gift-SKU мягкой щётки (качество + тихий логотип) и карточку.  
2. Выдавать **G0** после каждой **профгигиены** + памятка.  
3. **G2** орто-воск+ёршик — только после установки брекетов.  
4. Не менять розничные цены витрины.  
5. Метрики: доля гигиен с `gift_issued`; `memo_printed`; `next_visit_booked`; `care_taken` (ирригатор/паста) — наблюдение, не KPI давления.  
6. Спросить Атабека: допустим ли soft incentive «щётка в наборе при записи следующего визита» или только безусловный gift после процедуры.

---

## Источники практик (агентство, не clinic claims)

- Welcome / hygiene kits как daily brand touchpoint (toothbrush 2×/day).  
- Качество mid-range brush > ultra-cheap giveaway (сигнал стандарта клиники).  
- Сегментация kits: kids / ortho / post-procedure comfort.  
- Себестоимость готовых wholesale kits часто порядка $1–3/пациент; локальная закупка в Бишкеке — отдельный прайс клиники.  
- Связка gift → recall booking — опциональный soft incentive, не обязательный для Expert Dental.
