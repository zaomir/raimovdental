# RAIMOV legal

Stores approved legal analysis and project-specific legal records for website, clinic, patient consent, data protection, Academy, future franchise and publication clearances.

Recommended split: `website/`, `clinic/`, `patient-consent/`, `data-protection/`, `academy/`, `franchise/`, `clearances/`.

This directory does not replace external counsel. Each conclusion must identify jurisdiction, source, reviewer, date, scope and unresolved questions.
