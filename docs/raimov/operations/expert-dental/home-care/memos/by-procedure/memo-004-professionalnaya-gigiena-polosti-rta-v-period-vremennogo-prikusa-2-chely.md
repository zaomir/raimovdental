# Памятка родителям: Профессиональная гигиена полости рта в период временного прикуса (2 челюсти)

## Сегодня вечером
1. Мягкая детская щётка по возрасту.
2. Паста с подходящим содержанием фтора — как сказал врач.
3. Помогите ребёнку с чисткой, если ещё не чистит самостоятельно.

## Дальше
- Следующая гигиена обычно через 3–6 месяцев.
- Герметизация / лечение кариеса — если врач рекомендовал отдельно.
