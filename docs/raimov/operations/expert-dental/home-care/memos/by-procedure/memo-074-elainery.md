# Памятка: Элайнеры

**Expert Dental Studio** · Бишкек

## Ношение
1. Каппы — по часам, которые назвал врач (часто ~20–22 ч/сутки).
2. Снимайте для еды и горячих напитков; перед надеванием чистите зубы.

## Уход за каппами
Щётка для капп + очищающие таблетки по рекомендации; не кипяток.

## Дальше
Чек-апы и следующие пары по графику; в конце — ретейнеры.
