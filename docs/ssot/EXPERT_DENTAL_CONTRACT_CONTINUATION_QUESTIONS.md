# Expert Dental — пакет вопросов для продолжения договора

## 0. Назначение

Единый реестр **заранее подготовленных вопросов**, которые нужны, чтобы продолжить работу по договору с клиникой Expert Dental / Атабеком Саидовичем (в т.ч. через ассистента клиники).

Этот SSOT **не заменяет** юридическое заключение и не фиксирует ответы. Он указывает, **где канон вопроса** и **что блокирует**.

Связанный операционный контур ухода после визита: `EXPERT_DENTAL_HOME_CARE_HANDOFF_SYSTEM.md` (DEC-787).

# 3. Письменный пакет для ассистента / клиники (C-01…C-27)

Источник: `research/raimov-profile/CLINIC_PENDING_PACKET.md`.

Формат ответа: **ДА / НЕТ / УТОЧНИТЬ** + вложение.

Блоки: юрлицо и бренд · должность/специализации врача · образование/сертификаты · Academy/сообщество · команда · media rights · кейсы/отзывы · контакты/карты · прайс и medical review текстовтов.

Смежный чеклист публикации: `site-raimovdental/CONTENT_REQUIRED_FROM_CLINIC.md`.

# 5. Данные от клиники для baseline / SF

Источник: элитная стратегия §21.

Обязательный минимум: доступы к картам, сайт/аналитика, CRM/телефония, врачи и графики, услуги и цены, статистика воронки, скрипты, кейсы/согласия, лицензии, политика данных.

Без этого честный расчёт success fee невозможен.

---

# 6. Как передавать ассистенту

1. Сначала **D-01…D-09** и **M-07, M-15** (доступ к данным и владелец сверки) — блокируют продолжение договора.  
2. Параллельно пакет **C-01…C-27** для публикации/доказательств.  
3. Home Care (DEC-787) — отдельный операционный трек; не смешивать с формулой SF в одном письме без явной пометки.
