Как RAIMOV DENTAL обрабатывает данные из форм сайта

Эта страница описывает, что происходит с данными, которые вы оставляете через формы «Обсудить развитие RAIMOV DENTAL» и «Профессиональный запрос в Academy» на сайте raimovdental.com.

Какие данные мы собираем

  • Имя.
  • Контакт для связи: телефон, Telegram, WhatsApp или e-mail.
  • Город и, при заполнении формы «Обсудить развитие», страна.
  • Роль или специальность, которую вы указали.
  • Текст вашего сообщения о цели обращения.

Для чего используются данные

Данные используются только для того, чтобы представитель RAIMOV DENTAL мог связаться с вами по указанному вами каналу и обсудить тему, с которой вы обратились. Мы не используем эти данные для рассылок, которых вы не запрашивали, и не передаём их третьим лицам для маркетинга.

Кто имеет доступ

Доступ к данным формы имеют только представители RAIMOV DENTAL, ответственные за обработку обращений. Технически данные сохраняются в защищённой базе данных, используемой сайтом для приёма заявок.

Аналитика сайта

Сайт использует минимальную аналитику посещений и кликов по кнопкам. Она не собирает содержимое ваших сообщений, имя, контакт или другие персональные данные — только факт события (например, открытие формы) и страницу, на которой это произошло.

Срок хранения и удаление

Данные хранятся столько, сколько необходимо для обработки вашего обращения и последующей коммуникации. Вы можете в любой момент попросить удалить свои данные — для этого напишите на контакт, указанный в вашей переписке с представителем RAIMOV DENTAL.

Согласие

Отправляя форму на сайте, вы подтверждаете согласие на обработку указанных данных для связи с RAIMOV DENTAL по теме вашего обращения. Текущая версия согласия: 2026-07-31.
