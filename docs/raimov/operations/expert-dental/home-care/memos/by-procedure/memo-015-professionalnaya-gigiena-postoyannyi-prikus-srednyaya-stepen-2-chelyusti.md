# Памятка: Профессиональная гигиена — постоянный прикус, средняя степень (2 челюсти)

**Expert Dental Studio** · Бишкек

Сегодня проведена профессиональная гигиена. Уход начинайте **сегодня вечером**.

## Сегодня вечером
1. Почистите зубы **новой мягкой** щёткой.
2. При чувствительности / тонкой эмали — низкоабразивная паста.
3. Межзубной уход — по рекомендации врача.

## Дальше
- Следующая гигиена: обычно через **3–4 месяца**.
- Найденные проблемы (кариес и др.) — отдельная запись.
- Лёгкая чувствительность 1–2 дня бывает часто.

## Когда связаться
Сильная боль, отёк, длительная кровоточивость дёсен.
