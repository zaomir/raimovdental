# Clinic growth

Stores the measurable growth system for Expert Dental Studio and later directly controlled RAIMOV DENTAL clinics: baseline, priority services, capacity, offers, diagnostic-product economics, treatment-plan conversion, retention, internal referrals and success-fee inputs.

**Retention / loyalty canon:** `docs/ssot/EXPERT_DENTAL_PATIENT_MOTIVATION_SYSTEM.md` (DEC-786) — Continuity + Expert Care 12 + Expert Points. Cohort economics for Care/Points must stay separate from advertising spend and success-fee formulas.

**Home care / retail handoff canon:** `docs/ssot/EXPERT_DENTAL_HOME_CARE_HANDOFF_SYSTEM.md` (DEC-787) — showcase + doctor care class + admin memo/basket; retail separate from success fee until agreed. Ops pack: `docs/raimov/operations/expert-dental/home-care/`.

**Contract continuation questions:** `docs/ssot/EXPERT_DENTAL_CONTRACT_CONTINUATION_QUESTIONS.md`.

Required rule: separate activity, funnel movement and cash received. No target or success-fee formula is canonical until baseline, attribution and clinic approval exist.
