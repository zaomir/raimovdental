# Памятка: Удаление зуба мудрости — тяжёлая степень

**Expert Dental Studio** · Бишкек

Первые сутки решают заживление лунки.

## Сегодня (24 часа)
1. Не полоскать интенсивно и не «высасывать» лунку.
2. Не есть/пить горячее; мягкая пища; жевать на другой стороне.
3. Не курить и не употреблять алкоголь в день удаления.
4. Не трогать лунку; холод снаружи — если рекомендовал врач.

## Уход
- День 0: средства ухода в лунку не нужны.
- Со 2–3 дня — очень мягкая щётка рядом с лункой.
- Аптека — только по схеме врача.

## Дальше
Контроль 3–7 дней; снятие швов при наличии; план замещения зуба (имплант / мост / временный протез) — по рекомендации.

## Когда срочно связаться
Кровотечение >20–30 мин при тампоне; сильный отёк; температура; резкая боль на 2–3 сутки.
