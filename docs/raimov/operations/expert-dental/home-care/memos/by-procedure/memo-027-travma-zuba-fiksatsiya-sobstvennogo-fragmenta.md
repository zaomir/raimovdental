# Памятка: Травма зуба — фиксация собственного фрагмента

**Expert Dental Studio** · Бишкек

## Сегодня
1. Пока есть анестезия — не жевать на этой стороне.
2. Мягкая пища; холодное/горячее — по самочувствию, без экстремумов.

## Домашний уход
1. Чистите зубы **мягкой** щёткой 2 раза в день.
2. Межзубные промежутки — нить / ёршики / ирригатор, если рекомендовал врач.
3. Средства можно взять на ресепшене или купить в магазине — важен класс ухода, не бренд.

## Дальше
Контроль жизнеспособности зуба по графику врача; при ухудшении может понадобиться эндодонтия.

## Когда связаться
Острая боль, отёк, фрагмент отклеился, зуб стал темнее.
